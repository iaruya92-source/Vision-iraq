# Vision Iraq - منصة فيجن العراق

منصة إعلانات سوبر أب محلية للعراق، تشمل قسم العقارات، أصحاب المهن، والأجهزة الكهربائية.

## المميزات

### 🔐 التسجيل والدخول
- تسجيل دخول برقم الهاتف العراقي
- OTP وهمي (1234) للبيئة التطويرية
- تسجيل جديد باسم، رقم هاتف، محافظة
- تسجيل دخول مباشر بـ OTP

### 📢 إدارة الإعلانات
- إضافة، تعديل، حذف الإعلانات
- صور متعددة لكل إعلان
- تعيين نطاق النشر (محافظة واحدة أو كل العراق)
- فترة سماح 10 أيام، تنبيه بعد 5 أيام

### 🔍 البحث والتصفية
- حسب المحافظة
- حسب نوع العقار / المهنة / الجهاز
- حسب السعر، المساحة، عدد الغرف
- البحث بالنص

### 📄 صفحة التفاصيل
- عرض كامل للإعلان مع صور
- إعلانات مشابهة
- التواصل عبر WhatsApp (إعادة توجيه للإدارة)
- رقم الإدارة: 07833779833

### 👤 لوحة تحكم المستخدم
- إحصائيات الإعلانات
- إعلاناتي (نشطة، منتهية، قيد المراجعة)
- الملف الشخصي (تعديل الاسم، المحافظة، صورة البروفايل)

### 🛠️ لوحة إدارة المنصة
- رقم مدير: 07833779833
- مراجعة وإدارة الإعلانات
- إدارة المستخدمين (تعيين/إلغاء أدمين)
- إدارة المحافظات والتصنيفات
- إعدادات المنصة (نص التواصل، رقم الهاتف)
- إحصائيات كاملة للمنصة

### 🎨 التصميم
- RTL كامل بالعربية
- ألوان أزرق داكن وذهبي
- خط Tajawal
- أيقونات Font Awesome 6
- تصميم احترافي وسهل الاستخدام

18 محافظة عراقية بياناتها جاهزة
