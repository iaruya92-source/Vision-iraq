# Vision Iraq - منصة فيجن العراق

منصة سوبر أب محلية للعراق، تبدأ بقسم العقارات (فعال 100%) والباقي قادم قريباً.

## المميزات

- **تسجيل دخول برقم الهاتف**: OTP وهمي (1234) للتسهيل في البيئة التطويرية.
- **إدارة الإعلانات**: إضافة، تعديل، حذف، مع صور متعددة.
- **بحث وتصفية متقدم**: حسب المحافظة، نوع العقار، السعر، المساحة، الغرف.
- **صفحة تفاصيل**: عرض كامل للإعلان مع صور وعقارات مشابهة.
- **لوحة تحكم المستخدم**: إحصائيات، إعلاناتي، الملف الشخصي.
- **لوحة إدارة**: مراجعة الإعلانات، إدارة المستخدمين، إحصائيات المنصة.
- **تصميم RTL حضاري**: ألوان أزرق داكن وذهبي، احترافي وسهل الاستخدام.
- **18 محافظة عراقية**: بيانات مبدئية جاهزة.

## التقنيات

- **Backend**: Flask, Flask-SQLAlchemy, Flask-Login
- **Database**: SQLite
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Icons**: Font Awesome 6
- **Font**: Tajawal (Arabic)

## التشغيل

```bash
pip install flask flask-login flask-sqlalchemy
python app.py
```

افتح المتصفح على: `http://localhost:5000`

## ملاحظات

- قسم العقارات هو القسم الوحيد النشط حالياً. باقي الأقسام تظهر "قريباً".
- يمكن الوصول لإدارة المنصة عبر إضافة `make-admin/<phone>` في الرابط (مثال: `/admin/make-admin/07701234567`).
- البيانات الأولية (seed) تُنشأ تلقائياً عند أول تشغيل.
- مجلد `uploads/properties/` يُنشأ تلقائياً لتخزين صور العقارات.
